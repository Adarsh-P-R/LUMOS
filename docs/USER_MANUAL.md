# LUMOS user manual

The full manual is [LUMOS-user-manual.pdf](LUMOS-user-manual.pdf) in this folder (17 pages, A4).

It covers:

1. Introduction and quick start
2. Screen layout
3. Working on the table: adding, moving, rotating, snapping, locking
4. Parts reference: every part and its settings
5. Beam physics: propagation, clipping, polarisation, AOMs and AODs, fibre coupling, damage thresholds, limitations
6. Beams tab
7. Control tab
8. Catalogue parts, mounting and footprints
9. Shop tab
10. Table tab, files and examples
11. Tips, troubleshooting and FAQ
